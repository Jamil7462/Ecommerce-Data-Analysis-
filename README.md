# Ecommerce Data Analysis

A practical e-commerce data analysis project using **Excel and SQL**.

## Project Overview

This project focuses on analyzing e-commerce order data to find useful business insights and practice real-world data analyst tasks.

## Tools Used

- Microsoft Excel
- Oracle SQL
- GitHub

## Dataset

The project uses an e-commerce orders dataset containing information such as:

- Order ID
- Customer details
- Product details
- Quantity
- Price
- Order status
- Order date
- Other order-related information

## Analysis Performed

### Excel
- Data cleaning
- Data sorting and filtering
- Basic formulas
- Conditional analysis
- Summary calculations

### SQL
- SELECT queries
- WHERE conditions
- Filtering data
- Aggregate functions
- GROUP BY
- ORDER BY
- Views
- Business-oriented analysis queries
